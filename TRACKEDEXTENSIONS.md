# Tracked File Extensions

This tool tracks and processes files with the following extensions.  
The list is grouped by category for easier reading.

## Programming Languages

- JavaScript & TypeScript family  
  `.js`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.jsx`

- Python  
  `.py`

- Java  
  `.java`

- C / C++  
  `.c`, `.h`, `.cpp`, `.cc`, `.cxx`, `.hpp`

- C#  
  `.cs`

- Go  
  `.go`

- Rust  
  `.rs`

- Ruby  
  `.rb`

- PHP  
  `.php`

- Swift  
  `.swift`

- Kotlin  
  `.kt`, `.kts`

- Scala  
  `.scala`

- Dart  
  `.dart`

- R  
  `.r`

- Julia  
  `.jl`

- Lua  
  `.lua`

- Perl  
  `.pl`

- Shell scripting  
  `.sh`, `.bash`, `.ps1`

- Assembly  
  `.asm`, `.s`

- Fortran  
  `.f`, `.f90`

- COBOL  
  `.cob`

- Groovy  
  `.groovy`

- Haskell  
  `.hs`

- Elixir  
  `.ex`, `.exs`

- F#  
  `.fs`, `.fsi`, `.fsx`

- Clojure  
  `.clj`, `.cljs`, `.cljc`

- Lisp family  
  `.lisp`, `.el`

- Nim  
  `.nim`

- Zig  
  `.zig`

- V  
  `.v`

- Solidity  
  `.sol`

- Godot (GDScript)  
  `.gd`

- Ada  
  `.ada`, `.adb`, `.ads`

- OCaml  
  `.ml`, `.mli`

- Crystal  
  `.cr`

- Pony  
  `.pony`

- Others  
  `.awk`, `.pro`, `.tcl`, `.rkt`, `.e`, `.smalltalk`

## Markup, Documentation & Data Formats

- HTML  
  `.html`, `.htm`, `.xhtml`

- XML & related  
  `.xml`, `.xaml`, `.opml`

- Markdown & variants  
  `.md`, `.markdown`, `.mdx`

- reStructuredText  
  `.rst`

- AsciiDoc  
  `.adoc`

- LaTeX  
  `.tex`, `.bib`

- Configuration & data  
  `.yml`, `.yaml`, `.json`, `.jsonc`, `.toml`, `.ini`, `.cfg`

- Tabular data  
  `.csv`, `.tsv`

- Vector graphics  
  `.svg`

**Not currently tracked** :  
`.org`, `.wiki`, `.txt`

## Styling / CSS / UI

- Standard & preprocessors  
  `.css`, `.scss`, `.sass`, `.less`, `.styl`, `.pcss`, `.postcss`

- Tailwind / atomic CSS  
  `.tailwind.css`

- CSS Modules  
  `.module.css`, `.module.scss`

**Not currently tracked** :  
`.qml`, `.ux`, `.themes`, `.tokens.json`

---

This list is defined in code as `TRACKEDEXTENSION` and may be updated over time.  
If you're missing an extension that should be supported → feel free to open an issue or PR!
